# 2D DEM Simulation



## Описание



Это проект для моделирования поведения ансамбля сферических частиц (в 2D — дисков) в замкнутом объёме
(вращающийся барабан). Программа реализует метод дискретных элементов (DEM) с учётом
упруго-демпфированных контактов, трения и момента сопротивления качению.



## Особенности



- Моделирование взаимодействия частиц по контактной модели

- Учёт нормальной и касательной силы трения (статического и динамического)

- Момент сопротивления качению

- Графический интерфейс пользователя

- Визуализация траекторий частиц и приводного момента



## Требования



- Python 3.7+

- numpy

- matplotlib

- PyQt5



## Установка



1. Создайте виртуальное окружение:


python -m venv venv





2. Активируйте виртуальное окружение:

- Windows: `venv\Scripts\activate`

- Linux/Mac: `source venv/bin/activate`



3. Установите зависимости:


pip install -r requirements.txt





## Запуск



Запустите основной скрипт:


python main.py





## Использование



1. Введите параметры симуляции в левой панели

2. Нажмите "Применить" для установки параметров

3. Нажмите "Старт" для запуска симуляции

4. Результаты отображаются в правой панели:

   - Вкладка "Траектории": графики движения частиц

   - Вкладка "Приводной момент": график момента во времени

   - Числовые значения: средний момент, пиковый момент и мощность



## Структура проекта



- `main.py` - точка входа

- `dem/` - основная логика моделирования

- `gui/` - графический интерфейс пользователя

- `visualization/` - визуализация результатов

- `utils/` - вспомогательные функции и конфигурации



## Модули



### dem/

- `particle.py` - класс частицы

- `contact_model.py` - модель контакта

- `geometry.py` - границы (стенки, барабан)

- `integrator.py` - интегратор Верле

- `simulation.py` - основной класс симуляции

- `force_calculation.py` - расчёт сил



### gui/

- `main_window.py` - главное окно приложения

- `input_widget.py` - панель ввода параметров

- `output_widget.py` - панель вывода результатов

- `simulation_thread.py` - поток для симуляции
