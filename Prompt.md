## Общая цель
Разработать программу для моделирования поведения ансамбля сферических частиц (в 2D — дисков) в замкнутом объёме (вращающийся барабан). Частицы взаимодействуют по заданной контактной модели, включающей:
- нормальную упруго-демпфированную силу (линейная модель или модель Герца — выбери более устойчивую для 2D);
- силу трения (статическое и динамическое трение Кулона);
- гранулометрический состав сферических частиц;
- момент сопротивления качению.
Программа должна:
1. Принимать исходные данные от пользователя через графический интерфейс.
2. Запускать симуляцию, на каждом временном шаге рассчитывая траектории частиц и приводной момент, необходимый для поддержания вращения барабана.
3. Отображать траектории частиц (графически) и числовые результаты (средний приводной момент, пиковый момент, мощность).
4. Иметь возможность пошагового просмотра анимации.

## Детальные требования к модулям
### 1. Частица (particle.py)
- Поля: id, radius, density, mass, inertia (I = 0.5*m*r^2), pos (np.array из двух элементов), vel (np.array), ang_vel (float), force (np.array), torque (float), history (список позиций для траектории).
- Метод `apply_force(force_vector, torque_value)` добавляет к текущим силам.
- Метод `update_history()` добавляет копию pos в history.
### 2. Контактная модель (contact_model.py)
Создай класс `ContactModel` с параметрами:
- kn, kt — нормальная и касательная жёсткости (kt = kn * 2/7 можно по умолчанию).
- gamma_n, gamma_t — коэффициенты демпфирования, которые вычисляются из коэффициента восстановления e (restitution_coeff). Для линейной модели: gamma_n = -2 * ln(e) * sqrt(kn * m_eff) / pi, где m_eff = m1*m2/(m1+m2). Если частица одиночная с границей, m_eff = m_particle.
- mu_s, mu_d — статический и динамический коэффициенты трения.
- rolling_friction_coeff — коэффициент сопротивления качению (обозначим mu_r).
- Метод `compute_forces(self, overlap, overlap_rate, tangential_displacement, rel_vel_tang, effective_radius, normal_unit_vector, particle1, particle2=None)` возвращает кортеж: (normal_force_vector, tangential_force_vector, rolling_torque_on_particle1, rolling_torque_on_particle2). Если второй частицы нет (граница), то rolling_torque_on_particle2 = 0.
  - Нормальная сила: Fn = kn * overlap + gamma_n * overlap_rate, направлена по normal_unit_vector.
  - Касательная сила: сначала вычисляется пробная сила упругости Ft_trial = -kt * tangential_displacement - gamma_t * rel_vel_tang. Если |Ft_trial| > mu_s * |Fn|, то действует динамическое трение: Ft = -mu_d * |Fn| * (rel_vel_tang / |rel_vel_tang|). Иначе Ft = Ft_trial.
  - Момент сопротивления качению: Mr = -mu_r * |Fn| * R_eff * sign(omega_rel), где R_eff = (r1*r2)/(r1+r2) для пары частиц, или r1 для частицы-стенка, omega_rel — относительная угловая скорость.
### 3. Границы (geometry.py)
Абстрактный класс `Boundary` с методом `detect_collision(particle)` -> (overlap, contact_point, normal, overlap_rate, tangential_velocity).
- `WallLine` — прямая стенка, задаётся точкой и нормалью (внутренняя область — против нормали). Метод вычисляет пересечение, overlap = radius - расстояние от центра до линии.
- `WallCircle` — окружность (барабан). Может вращаться с угловой скоростью omega_drum. Является одновременно границей и источником внешнего момента. Поля: center, radius, omega. Метод `detect_collision` должен определять перекрытие, если расстояние от центра частицы до центра круга > (radius_circle - radius_particle). Контактная точка — на внутренней поверхности круга, нормаль направлена наружу. Учитывай скорость поверхности в точке контакта.
Также `WallCircle` должен иметь метод `apply_driving_torque(torque)`, который суммирует реактивный момент от частиц. При расчёте приводного момента для поддержания постоянной угловой скорости барабана мы накапливаем крутящие моменты, действующие со стороны частиц на барабан, и меняем знак.
### 4. Интегратор (integrator.py)
Функция `velocity_verlet_step(particles, dt, contact_model, boundaries)`:
1. Полушаг скорости: v += 0.5 * a * dt, omega += 0.5 * alpha * dt, где a = force/mass, alpha = torque/inertia.
2. Обновление позиций: x += v * dt, angle += omega * dt.
3. Обнуление сил и моментов на частицах.
4. Вызов `compute_all_forces(particles, boundaries, contact_model)`.
5. Второй полушаг скорости с новыми силами.
6. Сохранение истории частиц.
### 5. Расчёт сил (force_calculation.py)
Функция `compute_all_forces(particles, boundaries, contact_model)`:
- Обходит все уникальные пары частиц (i < j). Если расстояние между центрами < sum(radii), вычисляет overlap и т.д., вызывает contact_model.compute_forces, распределяет силы и моменты на каждую частицу с правильным знаком.
- Для каждой границы и каждой частицы вызывает detect_collision. Если overlap > 0, вычисляет силы через contact_model и добавляет на частицу. Для `WallCircle` добавляет реактивный момент на барабан (с противоположным знаком).
- Сохраняет накопленный на `WallCircle` внешний момент в переменную экземпляра (для последующего расчёта приводного момента).
### 6. Симуляция (simulation.py)
Класс `Simulation`:
- Конструктор принимает `config` (объект utils.config.SimulationConfig) и создаёт частицы, границы, модель контакта.
- Метод `initialize_particles()`: создаёт N частиц со случайными положениями внутри барабана без перекрытий (простая упаковка, можно сеткой или случайно с проверкой перекрытий). Начальные скорости нулевые.
- Создаёт границы: один `WallCircle` (барабан) с заданной угловой скоростью.
- `step()` выполняет один вызов `velocity_verlet_step`, затем записывает текущий приводной момент (взятый с `WallCircle.applied_torque`) в список `torque_history`.
- `run()`: цикл по времени до `total_time`, вызывает `step()` и инкрементирует `self.time`.
- Метод `get_trajectories()` возвращает список историй всех частиц.

### Важные замечания по реализации
Все физические величины — в СИ.
Избегай излишней сложности: для обнаружения контактов используй наивный O(N^2) обход всех пар, т.к. частиц не более нескольких сотен.
Обязательно проверяй, чтобы частицы не перекрывались при инициализации; простой способ — генерировать центры по спирали или сеткой с последующей релаксацией (но для простоты можно просто разместить их на окружности внутри барабана).
Приводной момент равен -суммарному моменту, который частицы приложили к барабану (чтобы сохранить его угловую скорость постоянной).
Учти, что трение качения создаёт дополнительный крутящий момент на частицах, который нужно добавить в их суммарный момент.
Документируй ключевые методы строкой docstring.
